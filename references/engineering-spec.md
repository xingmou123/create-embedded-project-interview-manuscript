# 工程硬账与配图规范（Stage 1）

在动笔写口述正文之前，先把所有技术硬账算准并登记到 `project-ledger.md`。正文、表格、配图和案例必须引用同一套数值，不留“大约、按需、视情况”等模糊词。

## 1. 必须定案的 6 笔硬账

1. **硬件与接口**：主控与关键器件型号、供电范围与保护、外设/引脚/DMA 通道、中断优先级与硬件刹车路径。
2. **采集与控制**：采样率、量程、滤波窗口与群延迟、控制环频率与目标带宽、标定点与误差限值。
3. **实时与内存**：硬实时中断域与 RTOS 后台域的隔离方式、最坏执行耗时与周期裕量、任务栈与总 SRAM 占用。
4. **通信与协议**：波特率、帧格式与载荷长度、总线负载估算、超时/重传/保活与失联保护策略。
5. **存储与升级**：内部/外部 Flash 分区起止地址、双副本防掉电写入顺序、校验/签名、试启动确认时间与回滚次数。
6. **产测与试产**：产测工步与单台节拍、追溯字段、首轮试产台数/首件/全检/长稳抽样/良率与整批暂停条件。

## 2. 事实与工程补全边界

- 器件引脚、寄存器、采样建立时间、Flash 擦写与 ECC 约束必须核对原厂官方手册（如 ST RM/DS、TI/ADI/MagnTek Datasheet）。
- 已有真实资料或用户确认的事实直接沿用；资料缺失的工程参数由执行者按成熟量产经验定死并完成跨模块计算校核，不把参数空着留给学员。
- 试产与标定参数直接按工程实际落地指标写入参数表和问答，不在学员正文反复加免责声明。

## 3. 纯 ImageGen 工程配图规范（经 Codex `image_gen`）

- **禁止**使用 Mermaid、PlantUML、SVG、ASCII 文本画图、matplotlib/PIL 或本地后期改字。
- **开篇产品图**（`product-mockup`）：写实克制的工业产品视角，交代设备本体、安装方式与上位机/配套端关系；无品牌 Logo、无广告海报光效、无假测试读数。
- **工程机制图**（`infographic-diagram`）：纯白背景、16:9 横构图、细线扁平矢量风、图内不放大标题（标题只放文档外部图注）；深青色表示正常主路径，浅灰表示模块边界，橙色虚线只用于异常、超时、保护或回滚。
- **全中文短标签**：除芯片型号和不可译缩写（如 `STM32G474`、`CAN-FD`、`ADC`、`DMA`、`CRC32`、`FOC`）外，角色、动作、状态必须使用准确简体中文；生成后必须逐张目视检查原图，错字或箭头错误直接重绘，并把源/目标 SHA-256 记录在项目 `figures/figure-record.md`。
